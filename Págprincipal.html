Inteligencia Artificial: comprendiendo las redes neuronales

Aplicaciones y conceptos

Qué es la I.A

La inteligencia artificial es la habilidad que tienen las máquinas para imitar capacidades humanas como el razonamiento, el aprendizaje, la creatividad y la capacidad de planear.

Qué son las redes neuronales

Las redes neuronales son un método de la inteligencia artificial que permite a las computadoras aprender a procesar datos de manera similar al cerebro humano.

Su evolución a la IA

1958 - Perceptron: Frank Rosenblatt

Uno de los primeros modelos de redes neuronales binarias, aprendiendo a partir de datos de entrada.

1980 - Perceptrones multicapa (MLP)

Con múltiples capas ocultas, permitieron resolver problemas más complejos gracias al aprendizaje profundo.

1986-Retropropagación

Es un método para calcular gradientes de manera eficiente que hizo posible entrenar redes profundas. La retropropagación funciona propagando el error desde la capa de salida a través de la red, ajustando los pesos para minimizar el error general. Esta innovación permitió el desarrollo de redes neuronales más complejas capaces de resolver una gama más amplia de problemas.

1997-Long Short Term Memory - Redes LSTM

Es un tipo de red neuronal recurrente especialmente diseñada para evitar que la salida de la red neuronal para una entrada dada se deteriore o explote a medida que pasa por los ciclos de retroalimentación.

2000-Aprendizaje Profundo

Es el campo de la inteligencia artificial que enseña a las computadoras a procesar datos de una manera que se inspira en el cerebro humano. Este campo muestra como una red neuronal de varias capas podría ser pre entrenada con una capa a la vez.

2014-Actualidad-Redes generativas (GAN)

Consisten en dos redes (un generador y un discriminador) que compiten entre sí para crear datos realistas. Las GAN se han utilizado para generar de todo, desde imágenes fotorrealistas hasta datos sintéticos para entrenar otros modelos de IA.
